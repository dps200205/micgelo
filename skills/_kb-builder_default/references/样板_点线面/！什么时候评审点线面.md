# 什么时候评审点线面

## 一句话定位
检查画面里的点（停顿节点）、线（方向与路径）、面（块面区域）是否组织有效：焦点找得到、引导读得通、大块面不被拆碎、缩小后仍然成立。

## 什么时候评
- 除下方“什么时候不评”列出的情况外，场景概念设计图都要评，作为构成的基础检查。
- 出现以下问题信号时必须评：画面散、堵、平、碎、缺少引导、层次不清。
- 需要检查主视觉、轮廓、装饰、材质细节是否相互配合时。
- 更换画幅、裁切、缩放或增加细节之后，需要复查。

## 什么时候不评
- 评审目标只是透视、结构、比例、内容准确性等专项时。点线面评审不能代替这些专项评审。
- 【待确认】三视图、结构拆解图、线稿推导图这类以说明结构为主、尚未形成完整画面构成的图。

## 需要的信息
- 来自用户说明：最终观看尺寸或用途（D16）；预期主导形式，可选（D02）；是否追求多类平衡（D14）；是否以均匀纹样为目标（D03、D05）。
- 来自场景解析：主体或焦点区、成组的重复元素、引导线、主要块面、点状元素群。
- 画面中如有比例参考人物、标注等非美术内容，需在用户说明中注明，避免它们被当作画面元素来评。

## 与其他知识块的关系
- **聚散与疏密**（待迁入）：D12 讨论的是聚集之后整体读起来像什么，具体的疏密检查在该块中。两块同时评时，D12 与聚散 J09 合并判断。
- **构图与引导**（待建设）：D06、D07 涉及视线引导。该块建成后，全局视线路径以它为准，点线面只检查“线本身是否成立”。
- **黑白灰画面层级**（待建设）：D13 涉及高光和暗部。明度层级本身以该块为准，点线面只看光影细节是否破坏构成。

| D01 | 关键元素在实际分析范围内发挥预期作用 | 有承担聚焦、引导或块面任务的元素 | 关键元素在整图中是否仍然清楚可见 |
| D02 | 画面的主导构成符合表达目标 | 总是适用；未指定目标时只描述 | 画面主要靠点、线还是面来组织 |

| D05 | 多点分布形成可读的停顿关系 | 有多个点状元素，不是均匀纹样 | 点是否处处同样醒目、是否抢主体 |
| D06 | 承担引导任务的线具有有效连续性 | 有承担引导的线 | 线能否连续读下去、是否通向主体 |
| D07 | 需要形成强线感时，跨度与显著性足够 | 有承担全局流动的线 | 线的有效跨度与对比度 |
| D08 | 线宽与面感的关系符合设计意图 | 有条带状元素 | 条带读起来像线还是像面 |
| D09 | 主要块面的形状与归属清楚 | 有墙、地面、天空等大块面 | 大块面是否完整、是否被切碎 |
| D10 | 正形与负空间共同支持形体识别 | 总是适用 | 相邻形体是否粘连；是否有抢眼碎缝 |
| D11 | 轮廓的节点与流动特征符合所需感受 | 有主体或关键形体轮廓 | 主体轮廓是否清楚、是否到处破碎 |
| D12 | 点线聚集后的整体性质没有偏离目标 | 有点群、排线、重复元素群 | 群组整体读成单个元素、路径还是块面 |
| D13 | 光影与材质细节没有破坏构成 | 有明显的光影或材质细节 | 碎高光是否嘈杂、是否抢主体 |
| D14 | 追求多类平衡时，各类确实具有可感知的分量 | 用户明确要求多类平衡 | 被要求的那几类是否都看得出来 |
| D15 | 各类元素的分布形成有意的整体关系 | 总是适用 | 是否意外偏重一侧；两半是否都能留住视线 |
| D16 | 最终观看条件下，必要层次仍然成立 | 总是适用（默认检查缩略图） | 缩小后主体和群组是否仍可辨认 |
